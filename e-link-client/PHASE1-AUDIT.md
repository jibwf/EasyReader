## 建议改进优先级

### 高优先级

1. **拆分 ViewModel** - 将 3090 行拆分为 AuthManager、SyncManager、ReadingManager 等
2. **添加依赖注入** - 使用 Hilt 或手动 DI，支持单元测试
3. **补充测试** - 至少覆盖 ViewModel 核心逻辑和 Repository

### 中优先级

4. **修复默认 URL 不一致** - 统一代码和文档
5. **优化 SettingsPane** - 使用回调接口或状态 holder
6. **添加 ProGuard 规则** - 确保 Release 构建正常

### 低优先级

7. **漫画图片渲染** - 从 URL 占位符升级为真实图片
8. **实体按键自定义** - 添加设置 UI
9. **Room 数据库迁移** - 替换文件 JSON 存储

## 总结

墨水屏客户端 Phase 1 主体功能已完成，核心能力（阅读、同步、离线、设备交互）均可用。主要差距在代码质量和测试覆盖。建议下一阶段重点：
