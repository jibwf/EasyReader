# 有声书播放界面UI重新设计

> [!NOTE]
> This document may not reflect the current implementation.
> See the final report for up-to-date state:
> [Final Report](../reports/audiobook-player-ui-redesign.md)

## [S1] 问题

当前有声书播放界面视觉风格不够舒适，用户希望采用喜马拉雅风格的简洁现代设计。同时需要增加播放历史、播放列表和收藏功能。

## [S2] 解决方案概述

采用喜马拉雅风格的播放界面设计，主要包括：

1. **视觉风格**：渐变色背景 + 大封面图 + 底部控制栏
2. **新增功能**：播放历史、播放列表、收藏功能
3. **技术实现**：基于现有React组件重构，使用Tailwind CSS实现渐变效果

## [S3] 设计细节

### 视觉设计

- **背景**：从封面图提取主色调，生成线性渐变背景
- **封面区域**：居中显示，圆角设计，带毛玻璃效果
- **控制按钮**：白色圆形按钮，带阴影效果
- **进度条**：白色进度条，带时间显示
- **底部设置**：定时、播放速度、目录、收藏等功能图标

### 新增功能

1. **播放历史**：
   - 记录每本书的播放进度
   - 支持断点续播
   - 显示最近播放的书籍列表

2. **播放列表**：
   - 用户可以创建自定义播放列表
   - 支持添加/删除章节
   - 支持排序和播放顺序设置

3. **收藏功能**：
   - 收藏喜欢的章节或有声书
   - 收藏列表单独显示
   - 支持取消收藏

### 技术实现

- **渐变色生成**：使用CSS `linear-gradient`，颜色从封面图提取
- **毛玻璃效果**：使用CSS `backdrop-filter: blur()`
- **响应式设计**：适配不同屏幕尺寸
- **状态管理**：使用zustand管理播放状态
